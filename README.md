# محاكي تركيب الشبكة المحلية ثلاثي الأبعاد

محاكي تعليمي تفاعلي باللغة العربية لتعلّم أساسيات بناء وإعداد شبكة محلية (LAN). يقدّم بيئة ثلاثية الأبعاد تحاكي الأجهزة والكابلات والمودم، إلى جانب واجهات أنظمة تشغيل افتراضية وأنشطة تطبيقية واختبار ختامي.

## ما الذي يقدّمه المحاكي؟

- تركيب شبكة محلية بين حاسوب مكتبي وحاسوب محمول وهاتف ومودم.
- توصيل كابلات الشبكة وإدارة حالة تشغيل الأجهزة.
- إعداد شبكة Wi-Fi، وتغيير اسمها وكلمة مرورها وإعدادات الأمان.
- محاكاة الحصول على عناوين IP والاتصال بالشبكة المحلية.
- مشاركة ملفات وقرص وطابعة بين الأجهزة داخل المحاكي.
- استخدام واجهات مبسطة لنظامي Windows وAndroid ومتصفح وإعدادات مودم.
- مراحل إرشادية متدرجة، ملاحظات تعليمية، تقييم ختامي، وشهادة قابلة للطباعة.

## التشغيل

لا يحتاج المحاكي إلى تثبيت أو إلى خادم ويب.

1. أبقِ ملف `محاكي تركيب الشبكة.html` ومجلد `assets` في المكان نفسه.
2. افتح ملف `محاكي تركيب الشبكة.html` بالنقر المزدوج عليه، أو من خلال أي متصفح حديث مثل Microsoft Edge أو Google Chrome أو Firefox.
3. ابدأ من لوحة المراحل، واتبع الخطوة المعروضة ثم نفّذها داخل المشهد أو داخل واجهات الأجهزة.

> يعمل المحاكي بالكامل دون اتصال بالإنترنت. لا تحذف مجلد `assets` ولا تغيّر موقعه النسبي بجانب ملف HTML، لأنه يحتوي على الخطوط والأيقونات والمكتبات اللازمة لعرض الواجهة والمشهد ثلاثي الأبعاد.

## مسار تعليمي مقترح

1. شغّل الأجهزة المطلوبة.
2. صِل طرفَي كابل RJ45 بين المنافذ المناسبة في المشهد.
3. افتح واجهة المودم من المتصفح الافتراضي عبر `192.168.1.1`.
4. فعّل Wi-Fi واضبط الاسم وكلمة المرور والحماية عند الحاجة.
5. صِل الحاسوب المحمول والهاتف بالشبكة اللاسلكية.
6. نفّذ مهام مشاركة الملفات والقرص والطابعة.
7. أكمل الاختبار الختامي واطبع الشهادة إذا رغبت.

## المتطلبات التقنية

- متصفح حديث يدعم JavaScript وWebGL.
- يفضّل تشغيله على شاشة بحجم متوسط أو كبير لتجربة أفضل، مع دعم الواجهة للأجهزة الأصغر.
- لا توجد حاجة إلى اتصال إنترنت بعد الحصول على ملفات المشروع كاملة.

- يمكن نقل مجلد المشروع كاملًا إلى جهاز آخر أو إلى وسيط تخزين وتشغيله بالطريقة نفسها دون إعدادات إضافية.
